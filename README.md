NBA Basketball Match Predictor 🏀
----------------------------------
Predict the winners of basketball games in the NBA using python and machine learning.
Uses box score data that was obtained through web scraping

Requirments 
----------------------------------
1. **Install prerequisites**
   - [Python 3.10+](https://www.python.org/downloads/)
   - [Visual Studio Code](https://code.visualstudio.com/) with the **Python** and **Jupyter** extensions
   - [Git](https://git-scm.com/)

2. **Clone the repository**
   ```bash
   git clone https://github.com/Arshpatel10/NBA-Basketball-Match-Predictor.git
   cd NBA-Basketball-Match-Predictor

### 3. Create & activate a virtual environment
- **macOS/Linux**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate

--**Windows**
  ```bash
  py -m venv .venv
  .venv\Scripts\activate

### 4. Install dependencies
```bash
python -m pip install --upgrade pip
